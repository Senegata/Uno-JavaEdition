# UNO Java Edition 🎴

UNO Java Edition is a console-based recreation of the classic UNO card game, built entirely in Java.  
Play in **Single Player mode** against a simple AI or in **Two Player mode** locally.  
Match colors or numbers, draw cards, and try to empty your hand before your opponent.

## 🎮 Features
- Single Player (vs AI)
- Two Player local mode
- Turn-based gameplay
- Card validation (match by color or number)
- Deck, table, and hand management
- Colorful ASCII art welcome screen and win banner
- Clean and modular Java structure
